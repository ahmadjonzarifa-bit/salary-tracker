Полнофункциональный веб-трекер персональных финансов в стиле **2D ретро пиксельных игр** с дашбордом, интерактивными графиками, 8-битным звуковым движком и кнопками с кошачьими лапками 🐾!

---

## 🎨 Фирменная палитра
- **COLOR 1:** `#DFE94B` *(Неоновый лайм — золото казны, лут, доходы, бонусы)*
- **COLOR 2:** `#836CEC` *(Насыщенный сиренево-фиолетовый — мана, заклинания, расходы)*

---

## 🕹️ Ключевые возможности

### 1. Полный цикл CRUD (Журнал квестов)
- **Create (Создание):** Добавление дохода или расхода с выбором гильдии/категории, даты и описания.
- **Read (Просмотр и поиск):** История операций с фильтрацией по дате, типу (доход/расход), категориям и сортировкой.
- **Update (Редактирование):** Изменение записей в ретро-модальном окне с мгновенным пересчетом баланса.
- **Delete (Удаление):** Сожжение свитков с подтверждением.

### 2. Аналитический дашборд и графики (Chart.js)
- **Баланс казны:** Автоматический расчет золота со статусом (Казна полна / Дефицит HP).
- **Сводка доходов и трат:** Количество операций и точные суммы.
- **Норма сбережений (%):** Процент сохраненных средств.
- 📊 **Баттл Золото vs Мана:** Столбчатый график сравнения поступлений и трат по месяцам.
- 🍩 **Круговые диаграммы:** Структура трат и источников золота по категориям.
- **Фильтр периодов:** Все время, текущий месяц, прошлый месяц, год или выбор диапазона дат.

### 3. 🐾 Интерактивные кошачьи лапки и 8-BIT Звук
- **Кнопка «ЛАПКА» (Кот Удачи / Maneki-Neko):** Синтезирует 8-битное мяуканье (`Web Audio API`) и разбрасывает золотистые отпечатки лапок 🐾!
- **Эффект отпечатков лапок:** Анимированные следы при нажатии на интерактивные кнопки.
- **8-Bit звуковой движок:** Звуки монетки Марио, ретро-удар при удалении и щелчки аркадного меню.
- **Переключатель звука:** Возможность включить/выключить аудио одним кликом.

### 4. Дополнительно
- 🌗 **Светлая и тёмная темы** с адаптивной контрастностью текстов (WCAG AAA).
- 💱 **Мультивалютность:** ₽ (RUB), $ (USD), € (EUR), ₸ (KZT), UZS (сум).
- 💾 **Автосохранение:** Сохранение всех данных в `localStorage`.
- 📁 **Сейвы и экспорт:** Экспорт в CSV (для Excel), экспорт и импорт JSON-сейвов.

## 🚀 Быстрый старт

Проект полностью автономный и не требует установки сборщиков или серверов:
1. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/<ваш-логин>/salary-tracker.git
   ```
2. Откройте файл `index.html` в любом браузере двойным кликом!

Либо запустите локальный сервер:
```bash
python -m http.server 8080
```
и перейдите на `http://localhost:8080`.
